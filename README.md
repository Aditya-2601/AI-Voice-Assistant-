# About
Hello buddies! This is an AI Voice Assistant made using Google Gemini API.

# Requirements
1) This program requires installing 3 external modules (google-genai , Speech_Recognition , pyttsx3).
Run the following commands in your terminal to install them:

```python
pip install google-genai
```

```python
pip install SpeechRecognition
```

```python
pip install pyttsx3
```

2) It requires an API Key of Google Gemini to run the model. Get the api key from https://aistudio.google.com/app/apikey
